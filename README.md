# Grassmasters MTL

A marketing site for Grassmasters MTL, built with Next.js.

> [!NOTE]
> This project was originally scaffolded with [Lovable](https://lovable.dev) as
> a TanStack Start app and has since been converted to Next.js (App Router).
> As a result it is no longer edited through the Lovable editor.

## Development

You need Node.js.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS
